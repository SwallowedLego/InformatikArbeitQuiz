Frage 1 HTML-Aufbau
Welches ist die korrekte Grundstruktur eines HTML-Dokuments?
A) <html><head></head><body></body></html>
B) <!DOCTYPE html><html><head></head><body></body></html>
C) <html><body></body></html>
D) <head><body></body></head>
✓ Lösung:
B) Die korrekte Struktur beginnt mit <!DOCTYPE html>, gefolgt von <html>, dann <head> und <body> Bereichen. Der DOCTYPE definiert den HTML5-Standard.
Frage 2 Tags/Attribute
Ergänze: Das Meta-Tag für die Zeichenkodierung lautet:
<meta = "">
✓ Lösung:
<meta charset = "UTF-8"> - Das charset-Attribut definiert die Zeichenkodierung des Dokuments.
Frage 3 Semantische Elemente
Welches HTML5-Element sollte für den Hauptinhalt einer Seite verwendet werden?
A) <div id="main">
B) <main>
C) <content>
D) <section>
✓ Lösung:
B) Das <main>-Element ist das semantische HTML5-Element für den Hauptinhalt. Es sollte nur einmal pro Seite verwendet werden.
Frage 4 Typische Fehler
Finde den Fehler in diesem Code:
<img src="bild.jpg" alt="Ein Bild"></img>
✓ Lösung:
Das <img>-Tag ist ein selbstschließendes Tag und benötigt keinen schließenden Tag. Korrekt: <img src="bild.jpg" alt="Ein Bild"> oder <img src="bild.jpg" alt="Ein Bild" />
Frage 5 Überschriften
Welche Überschriften-Hierarchie ist korrekt?
A) h1 → h3 → h2 → h4
B) h1 → h2 → h3 → h4
C) h6 → h5 → h4 → h3
D) Man kann beliebig springen
✓ Lösung:
B) Überschriften sollten hierarchisch von h1 (wichtigste) bis h6 (am wenigsten wichtig) verwendet werden, ohne Ebenen zu überspringen.
Frage 6 Listen
Ergänze die Tags für eine ungeordnete Liste:
<>

<>Punkt 1</>

</>
✓ Lösung:
<ul>
  <li>Punkt 1</li>
</ul>
ul = unordered list (ungeordnete Liste), li = list item (Listenelement)
Frage 7 Links
Welches Attribut wird verwendet, um einen Link in einem neuen Tab zu öffnen?
A) newtab="true"
B) target="_blank"
C) open="new"
D) window="new"
✓ Lösung:
B) Das target="_blank" Attribut öffnet den Link in einem neuen Tab/Fenster. Beispiel: <a href="url" target="_blank">Link</a>
Frage 8 CSS-Syntax
Korrigiere diese CSS-Regel:
p { color = red; font-size: 16px }
✓ Lösung:
Fehler:
1. "color = red" muss "color: red;" sein (Doppelpunkt statt Gleichheitszeichen)
2. Nach "16px" fehlt ein Semikolon
Korrekt:
p { color: red; font-size: 16px; }
Frage 9 CSS-Einbindung
Welche CSS-Einbindungsmethode hat die höchste Priorität?
A) Externe CSS-Datei (extern)
B) <style>-Tag im <head> (intern)
C) style-Attribut im HTML-Tag (inline)
D) Alle haben gleiche Priorität
✓ Lösung:
C) Inline-Styles (style-Attribut) haben die höchste Priorität, gefolgt von internen Styles (<style>-Tag) und externen CSS-Dateien. Dies nennt man die "CSS-Kaskade".
Frage 10 Block/Inline
<div> ist ein -Element,
<span> ist ein -Element.
✓ Lösung:
<div> ist ein Block-Element (nimmt die ganze Breite ein, neue Zeile),
<span> ist ein Inline-Element (nur so breit wie nötig, keine neue Zeile).
Frage 11 Farben
Welche Farbangabe ist NICHT gültig in CSS?
A) color: red;
B) color: #FF0000;
C) color: rgb(255, 0, 0);
D) color: (255-0-0);
✓ Lösung:
D) Die Syntax (255-0-0) ist ungültig. Gültige Farbangaben sind: Farbnamen (red), Hex (#FF0000), RGB (rgb(255, 0, 0)), RGBA, HSL, HSLA.
Frage 12 Attribute
Vervollständige den Link mit allen wichtigen Attributen:
<a ___="https://example.com" ___="Beispielseite">Klick hier</a>
✓ Lösung:
<a href="https://example.com" title="Beispielseite">Klick hier</a>
href = Hyperlink-Referenz (Ziel-URL)
title = Tooltip-Text beim Hovern
Frage 13 Absätze
Welches Tag wird für einen Absatz verwendet?
A) <paragraph>
B) <p>
C) <text>
D) <para>
✓ Lösung:
B) Das <p>-Tag (paragraph) wird für Textabsätze verwendet. Es ist ein Block-Element mit automatischem Abstand oben und unten.
Frage 14 CSS-Einbindung
Ergänze den Code zum Einbinden einer externen CSS-Datei im <head>:
< rel="" href="styles.css">
✓ Lösung:
<link rel="stylesheet" href="styles.css">
Das <link>-Tag mit rel="stylesheet" bindet externe CSS-Dateien ein.
Frage 15 Typische Fehler
Was ist falsch an diesem Code?
<p>Dies ist ein <strong>wichtiger</p></strong> Text.
✓ Lösung:
Die Tags sind falsch verschachtelt. Das <strong>-Tag wurde geöffnet, bevor <p> geschlossen wurde.
Korrekt: <p>Dies ist ein <strong>wichtiger</strong> Text.</p>
Regel: "First opened, last closed" - zuerst geöffnete Tags müssen zuletzt geschlossen werden.
Frage 16 Fachbegriffe
Was bedeutet "CSS" als Abkürzung?
A) Computer Style Sheets
B) Cascading Style Sheets
C) Creative Style System
D) Coded Style Syntax
✓ Lösung:
B) CSS = Cascading Style Sheets (Kaskadierende Stilvorlagen). "Cascading" bezieht sich auf die Art, wie Stilregeln vererbt und überschrieben werden.
Frage 17 Semantische Elemente
Ordne die semantischen HTML5-Elemente ihrer Bedeutung zu:
1. <header>
2. <nav>
3. <footer>
4. <article>
✓ Lösung:

Frage 18 Bilder
Welches Attribut ist beim <img>-Tag ZWINGEND erforderlich?
A) width und height
B) src und alt
C) title
D) class
✓ Lösung:
B) src (Bildquelle) und alt (Alternativtext) sind erforderlich. Der alt-Text ist wichtig für Barrierefreiheit und wird angezeigt, wenn das Bild nicht geladen werden kann.
Frage 19 Listen
Eine geordnete Liste wird mit dem Tag erstellt,
während eine ungeordnete Liste das Tag verwendet.
✓ Lösung:
Eine geordnete Liste wird mit dem Tag <ol> (ordered list) erstellt,
während eine ungeordnete Liste das Tag <ul> (unordered list) verwendet.
Beide verwenden <li> für die einzelnen Listenelemente.
Frage 20 CSS-Syntax
Welcher CSS-Selektor wählt ein Element mit der ID "header" aus?
A) .header { }
B) #header { }
C) header { }
D) *header { }
✓ Lösung:
B) #header { } wählt ein Element mit id="header" aus.
. = Klassen-Selektor (class)
# = ID-Selektor (id)
Ohne Symbol = Element-Selektor (Tag-Name)
* = Universal-Selektor (alle Elemente)
Frage 21 Media-Elemente
Welches Attribut ermöglicht es, dass ein Video automatisch abgespielt wird?
A) play="auto"
B) autoplay
C) auto="true"
D) start="auto"
✓ Lösung:
B) Das autoplay-Attribut startet das Video automatisch beim Laden der Seite.
Beispiel: <video src="video.mp4" autoplay controls></video>
Weitere wichtige Video-Attribute: controls (Steuerungselemente), loop (Wiederholen), muted (Stummschaltung).
Frage 22 Media-Elemente
Ergänze den Code für ein Audio-Element mit Steuerungselementen:
< src="musik.mp3" ></>
✓ Lösung:
<audio src="musik.mp3" controls></audio>
Das controls-Attribut zeigt Play-, Pause- und Lautstärke-Buttons an. Ohne dieses Attribut wäre das Audio nicht steuerbar.
Frage 23 Fachbegriffe
Was ist der Unterschied zwischen einem "Tag" und einem "Element"?
A) Es gibt keinen Unterschied
B) Ein Tag ist die Auszeichnung, ein Element besteht aus öffnendem Tag, Inhalt und schließendem Tag
C) Ein Element ist nur der öffnende Tag
D) Tags sind in HTML, Elemente in CSS
✓ Lösung:
B) Ein Tag ist die Markierung wie <p> oder </p>.
Ein Element ist das komplette Konstrukt: <p>Text</p> (öffnendes Tag + Inhalt + schließendes Tag).
Beispiel: Bei <h1>Überschrift</h1> sind <h1> und </h1> die Tags, das gesamte Konstrukt ist das h1-Element.
Frage 24 Fachbegriffe
Identifiziere im folgenden Code das Attribut und den Wert:
<img src="logo.png" width="200">
✓ Lösung:
Attribute: src, width
Werte: "logo.png", "200"

Ein Attribut ist die Eigenschaft (z.B. src, width, class).
Der Wert ist die Zuweisung zu dieser Eigenschaft (z.B. "logo.png", "200").
Syntax: attribut="wert"
Frage 25 HTML-Aufbau
Welche Elemente gehören in den <head>-Bereich?
A) <title>, <meta>, <link>
B) <p>, <div>, <h1>
C) <img>, <video>, <audio>
D) <ul>, <ol>, <li>
✓ Lösung:
A) Der <head> enthält Meta-Informationen über das Dokument:
• <title> = Seitentitel (im Browser-Tab)
• <meta> = Meta-Daten (Zeichenkodierung, Beschreibung, Keywords)
• <link> = Verknüpfungen (CSS-Dateien, Favicon)
• <style> = Interne CSS-Regeln

Der <body> enthält den sichtbaren Inhalt der Webseite (Texte, Bilder, Videos, etc.).
Frage 26 CSS-Syntax
Erkläre den Unterschied zwischen margin und padding anhand dieses Beispiels:
div { margin: 20px; padding: 10px; border: 2px solid black; }
✓ Lösung:
margin = Außenabstand (Abstand zwischen dem Element und anderen Elementen)
padding = Innenabstand (Abstand zwischen dem Rand und dem Inhalt)
border = Rahmen (liegt zwischen margin und padding)

Box-Model (von außen nach innen):
margin → border → padding → Inhalt
Frage 27 Semantische Elemente
Welches Element ist am besten geeignet für einen eigenständigen Blogbeitrag?
A) <section>
B) <article>
C) <div>
D) <aside>
✓ Lösung:
B) <article> ist für eigenständige Inhalte gedacht, die auch alleine Sinn ergeben (Blogposts, Nachrichtenartikel, Forenbeiträge).

Unterschiede:
• <section> = Thematischer Abschnitt, Teil eines größeren Ganzen
• <article> = Eigenständiger, wiederverwendbarer Inhalt
• <aside> = Nebenbemerkung, Sidebar, zusätzliche Info
• <div> = Generischer Container ohne semantische Bedeutung

Frage 29 Browser-Rendering
Was bedeutet "DOM" im Kontext von Webbrowsern?
A) Document Object Model
B) Data Output Method
C) Digital Online Media
D) Display Order Management
✓ Lösung:
A) DOM = Document Object Model
Der DOM ist die Baumstruktur, in die der Browser das HTML-Dokument umwandelt. Jedes HTML-Element wird zu einem Objekt (Knoten) im DOM-Baum.

Der Browser:
1. Lädt HTML-Code
2. Parst ihn und erstellt den DOM-Baum
3. Wendet CSS-Styles an
4. Rendert die Seite auf dem Bildschirm
Frage 30 Typische Prüfungsaufgabe
Ordne die HTML-Elemente ihren Funktionen zu:
Elemente: <nav>, <header>, <footer>, <main>, <aside> Funktionen: A) Hauptinhalt der Seite B) Kopfbereich mit Logo/Titel C) Navigationsmenü D) Fußbereich mit Copyright E) Sidebar mit zusätzlichen Infos
✓ Lösung:
<nav> = C) Navigationsmenü
<header> = B) Kopfbereich mit Logo/Titel
<footer> = D) Fußbereich mit Copyright
<main> = A) Hauptinhalt der Seite
<aside> = E) Sidebar mit zusätzlichen Infos

Merke: Diese Elemente strukturieren eine Seite semantisch (mit Bedeutung), nicht nur visuell. Sie helfen Suchmaschinen und Screenreadern, den Inhalt besser zu verstehen.
